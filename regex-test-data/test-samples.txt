# 规则图 JSON 导入测试样本
# 用法：在「正则表达式生成」中导入对应 .json，将下方样本粘贴到测试区（按行模式）

================================================================================
01-default-non-empty-line.json
规则：每一行非空
================================================================================
第一行有内容
第二行也有

空行应失败（下面留一空行）

最后一行

预期：第 1、2、5 行 ✅ | 第 3、4 行（空行）❌

================================================================================
02-numbered-list.json
规则：每一非空行以数字开头
================================================================================
1. 第一项
2) 第二项
09 带前导零也可以

普通文字行
  3. 有前导空格

预期：第 1、2、3 行 ✅ | 第 4、5 行 ❌

================================================================================
03-playlist-split.json
规则：每一非空行非空 + 包含「 - 」+ 按「 - 」拆成 2 段
================================================================================
周杰伦 - 晴天
林俊杰 - 江南
只有一段没有分隔符
歌手 - 歌名 - 多了一段

预期：第 1、2 行 ✅ | 第 3、4 行 ❌

================================================================================
04-playlist-sequence.json
规则：行匹配「非空 - 非空」段链，且包含「周杰伦」、不包含「Live」（忽略大小写）
================================================================================
周杰伦 - 晴天
周杰伦 - Live 演唱会
林俊杰 - 江南
周杰伦-Live版

预期：第 1 行 ✅ | 第 2、3、4 行 ❌

================================================================================
05-email-regex.json
规则：整行匹配邮箱格式
================================================================================
user@example.com
zhang.san+tag@mail.co.uk
not-an-email
user@example

预期：第 1、2 行 ✅ | 第 3、4 行 ❌

================================================================================
06-phone-cn-regex.json
规则：整行匹配中国大陆 11 位手机号
================================================================================
13812345678
19900001111
12812345678
1381234567

预期：第 1、2 行 ✅ | 第 3、4 行 ❌

================================================================================
07-url-regex.json
规则：整行匹配 http/https URL
================================================================================
https://www.example.com/path?q=1
http://localhost:8080
www.example.com
ftp://files.example.com

预期：第 1、2 行 ✅ | 第 3、4 行 ❌

================================================================================
08-id-card-regex.json
规则：整行匹配 18 位身份证号（格式级）
================================================================================
110101199003071234
44010619851212345X
11010119900307123
1101011990030712

预期：第 1、2 行 ✅ | 第 3、4 行 ❌（积木版校验 18 位结构，不校验月份）

================================================================================
09-email-or-url-line.json
规则：每一行包含 @ 或以 http 开头（忽略大小写）
================================================================================
联系邮箱 user@example.com
访问 https://toolbox.example.com
普通文本一行
HTTP://UPPER.CASE.COM/ok

预期：第 1、2、4 行 ✅ | 第 3 行 ❌
